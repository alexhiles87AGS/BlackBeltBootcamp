# BlackBeltBootcamp V4.0.1 — iPhone UX Patch

## Fixed

- Training Calendar width overflow on iPhone.
- Seven-day week selector now fits within the viewport.
- Mobile session cards no longer force horizontal page scrolling.
- Add Session inputs remain inside their panel.
- Workout Builder exercise rows, action buttons and draft fields now fit narrow screens.
- Removed nested scrolling from the mobile exercise-picker list in favour of natural page scrolling.
- Improved mobile saved-workout date/time controls.
- Corrected hamburger/top-bar alignment and safe-area spacing.
- Prevented profile name, email and role text overflowing the drawer profile card.
- Made the drawer navigation scroll independently so admin links are always accessible.
- Locked background page scrolling while the drawer is open.

## Retained

- Dashboard, Today, Exercise Library, FMA Classes, Nutrition, Progress and Achievements functionality.
- Supabase Auth, cloud sync, realtime refresh and all V4 data architecture.

## Database

No SQL changes are required.
