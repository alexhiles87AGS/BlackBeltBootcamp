# V4.0.1 Mobile QA Checklist

Test at iPhone widths of approximately 375px and 390px.

## Header and navigation

- Hamburger icon is vertically centred.
- Brand does not collide with sync/profile controls.
- Drawer opens from both the hamburger and More button.
- Profile name, email and role remain inside the profile card.
- Drawer can scroll to Admin Console and Exercise Import.
- Sign out remains reachable at the bottom.

## Training Calendar

- All seven days fit inside the calendar card.
- Previous/next week controls remain inside the frame.
- Selected-day title and session count wrap cleanly.
- Session cards do not create horizontal page scrolling.
- Date, time, type, saved workout and title inputs fit the Add Session panel.

## Workout Builder

- Workout details fields stack vertically.
- Body-area pills scroll horizontally without moving the page sideways.
- Exercise rows show name, muscles, Preview and Add without overflow.
- Exercise list uses the page scroll rather than a nested inner scroll.
- Draft exercise fields and action buttons stay within each card.
- Save Workout fills the mobile card width.
- Saved-workout date/time controls stack and remain usable.

## Regression checks

- Today remains unchanged.
- Exercise Library and videos work.
- FMA Classes work.
- Nutrition, Progress and Achievements work.
- Admin tabs and Exercise Import remain accessible.
